## 三条线路怎么选

### Pro：钱花在回程上

Pro 的回程三网都走 CN2 GIA，去程电信 AS4809、联通 AS4837 直连、移动经香港移动 AS58453 落地。这套组合的差别集中在晚高峰，白天测速看不出什么，晚上八点到十一点才是它和便宜机的分水岭。建站、跨境办公、给国内用户提供接口，选它不容易踩坑。代价是同配置比 EB 贵三到四成。

### EB：移动用户的高性价比选项

EB 走电信 AS9929 / AS58807 负载均衡、移动 CMIN2、联通 9929 回程。移动宽带用户用它，体验经常比 Pro 还顺；电信方向明显弱一档。这道选择题的答案取决于你家宽带：电信用户省下那几美元，换来的可能是晚高峰反复重连；移动用户选 EB 没什么可犹豫的。

### T1：不服务中国大陆

T1 走 telia、zayo、cogent 这类国际线路，对大陆方向不做任何优化。它卖的是带宽和流量，月付 6.90 美元就有 2TB 流量和 4Gbps 端口，同价位很难找到更宽的。面向海外用户的项目、备份节点、临时测试机，用它合适；指望它给国内访问加速，方向就错了。

## 续费会不会涨

DMIT 官方条款写明，你在某个订购周期内支付的价格，在该周期内不变。同时它保留随时修改官网定价的权利，不另行通知。两条合起来就是：**续费价等于续费时官网这个套餐的现行价，不保证等于你的首购价。**

换句话说，年付锁住的是一年，不是永久。如果这一年里官网调价，到期续费就按新价走。买的时候赶上促销价，促销期过了，续费回到正价，这在 VPS 行业是常态。

能真正锁住折扣的是带 RECURRING 字样的循环优惠码。这类码续费继续生效，首购时用上，后面每一期都按折后价算，比一次性折扣实在得多。特惠限量款（WEE 系列等）有用户反馈续费同价，但这条没有官方承诺，买之前看一眼套餐页有没有特别注明。社区里也有过硬件升级时同步升配、价格不变的案例，属于额外的好处，不能当成预期。

## 退款与换 IP：试错成本有多高

## 哪些人不用买 DMIT

**只追求绝对最低价的人。** 市面上有 2 到 3 美元一个月的机器，DMIT 的 T1 月付 6.90 美元起、Pro 月付 12.98 美元起，差价买的是带宽、超量处理和 IP 质量。跑一个自己看的测试环境，这些都用不上。

**需要随时迁移机房的人。** 套餐绑定机房，换机房等于重新买一份，这一点和后台可以自由切机房的品牌思路完全不同。

**需要稳定拿到特定地区原生 IP 的人。** 按库存轮换的商家在 IP 段上都有不确定性，DMIT 也不例外。

## 几个常被问到的问题

**能用支付宝吗？** 可以。支付宝、微信支付、PayPal、信用卡都支持。

**流量超了会怎样？** 不会停机，带宽降到 4Mbps 到 10Mbps 继续不限量用，次月重置。流量是按单向还是双向计，两版说法不一致，以套餐页说明为准，买之前扫一眼。

**香港为什么比洛杉矶贵这么多？** 带宽成本高，加上延迟低：香港 CN2 GIA 到国内大约 30 到 50ms，洛杉矶大约 130 到 160ms。香港套餐的月流量上限还明显更低，价格却更贵，两者是反向走的。

**月付能用优惠码吗？** 大部分不能。少数码明确写了包含月付，比如那条 10% 循环折扣的洛杉矶 Pro/EB 码。结账前点一次 Validate Code 就知道能不能用。

**会不会缺货？** 会，而且香港、东京比洛杉矶更常见。热门档位补货后可能几天内售罄，看到有货别拖。

**AN5 和 AN4 到底差在哪？** AN5 是 AMD EPYC 9005 加 DDR5。第三方评测汇总里，AN5 平台 Geekbench 6 单核约 2770、多核约 11829，硬盘 IO 平均在 839MB/s 左右，比 AN4 有明显提升。同一档配置 AN5 报价更高，你付的差价一部分买的是这代硬件。
